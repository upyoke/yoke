# Engineer — Ouroboros End-of-Session Reflection

Read before final output. Note observations when they occur so the final
sweep retains them. Parent PostToolUse Agent-tool hook
(`yoke_core.domain.reflection_capture_hook`) captures/persists structured
output; Engineer does not write reflection rows directly.

## End-of-Session Sweep

Review all useful observations, with multiple entries where warranted:
- `problem`: what code/validation/docs could prevent or improve friction?
- `process-improvement`: what improves workflow, handoffs, specs, testing,
  or commit discipline?
- `game-changing-idea`: what transformative capability would improve Yoke?
- `cross-agent-critique`: what specific Architect/PM/Tester input or downstream
  output needs improvement? Name the role and useful change.

## Entry Block Shape

Read `.claude/agents/references/_shared/ouroboros-reflection-contract.md` and run its
Pre-Submit Checklist. Use its exact canonical envelope, one entry per observation,
`agent: engineer`, real PREFIX-N/epic-task `context:` and exact category enums.
With no observations emit the empty envelope, never omit it.
