# Terms S–Z

[Yoke](../index.md) > [Index](index.md) > S–Z

Draft definitions and links to the current documentation.

## Secret

Sensitive capability configuration kept in its designated secret store. [Read more](../projects/capabilities.md).

## Self-hosted mode

Running a Yoke server on infrastructure you control. [Read more](../start/modes.md).

## Session

Usually a harness session here; a website sign-in session or browser QA session has a
different purpose. [Read more](../sessions/index.md).

## Session liveness

Whether a registered session is active, waiting, stale or ended. [Read more](../sessions/index.md).

## Session mode

The work a session declares it is doing, such as steering, execution or waiting. [Read more](../sessions/index.md).

## Setup

Connecting and configuring the machine, harnesses and project after installation. [Read more](../start/agent-setup.md).

## Setup checklist

Saved setup choices and current readiness facts, including the next action. [Read more](../start/agent-setup.md).

## Shared file

Project material stored for access across sessions and machines. [Read more](../projects/shared-files.md).

## Site

A named grouping used when declaring deployment environments. [Read more](../deployments/model/flows.md).

## Skill

A named procedure an agent reads to perform a kind of work. [Read more](../agents/commands.md).

## Smoke check

A focused QA check of essential behavior. [Read more](../verification/product-smoke.md).

## Stage

A step in an item workflow or a deployment flow; specify which. [Read more](../workflows/lifecycle.md).

## Stage receipt

Durable evidence of a non-QA deployment-stage attempt. [Read more](../deployments/model/stage-receipts.md).

## Stale session

A session eligible for reclaim under Yoke's ownership and liveness rules. [Read more](../sessions/index.md).

## Standalone QA

Running a project QA plan independently of a work item's progression. [Read more](../verification/standalone-plans.md).

## Steering

Coordinating work toward project direction, including deciding what can start and who
handles it. [Read more](../sessions/steering-report.md).

## Steering claim

Recorded ownership of a steering scope and, when specified, its planning document. [Read more](../strategy/index.md).

## Steering report

The report of work, holders, waits and problems that need coordination. [Read more](../sessions/steering-report.md).

## Strategy

The project's direction, priorities and planning documents. [Read more](../strategy/index.md).

## Success policy

The rules used to decide whether QA results satisfy an obligation. [Read more](../verification/success-policy.md).

## Task

A unit of work within a larger item; in an agent app, task can also mean the
conversation itself. [Read more](../items/model/tasks.md).

## Test machine

A configured machine used to execute QA with the required desktop or runtime. [Read more](../verification/test-machine-desktop.md).

## Transition

Advancing an item between workflow stages under its rules and gates. [Read more](../workflows/transitions.md).

## Uninstall

Removing Yoke software or project guidance, with choices about retained data. [Read more](../start/uninstall.md).

## Universe

The shared store of projects, work records and configuration that Yoke manages. [Read more](../start/concepts.md).

## Verification

Checking behavior and evidence against the required outcome. [Read more](../verification/index.md).

## Vision

The strategy document describing the project's chosen future state. [Read more](../strategy/index.md).

## Waiver

An authorized decision that discharges a QA obligation without a passing attempt. [Read more](../verification/requirement-discharges.md).

## Watcher

A long-running command that observes work and reports progress or completion. [Read more](../agents/rules/claude-long-commands.md).

## Work claim

Recorded ownership of an item by the session responsible for it. [Read more](../functions/claims.md).

## Workbench

Yoke's web interface for project work, coordination and configuration. [Read more](../start/concepts.md).

## Workflow

The versioned lifecycle an item follows, including stages, gates and execution rules. [Read more](../workflows/index.md).

## Workflow binding

The connection between a workflow segment and the skill responsible for executing it. [Read more](../workflows/transitions.md).

## Workflow pin

The specific workflow version an existing item follows. [Read more](../workflows/index.md).

## Worktree

A separate Git checkout used to isolate changes. [Read more](../functions/worktrees.md).

## WSL

The Linux environment on Windows used for supported Yoke and agent setup. [Read more](../start/windows-wsl.md).

## Yoke

The system that coordinates software delivery from direction through verified
outcomes. [Read more](../index.md).
