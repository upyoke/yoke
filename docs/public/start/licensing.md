Yoke's source is public at [github.com/upyoke/yoke](https://github.com/upyoke/yoke).
The repository's [LICENSE.md](https://github.com/upyoke/yoke/blob/main/LICENSE.md)
contains the governing terms.

## Fair Source and Apache 2.0 conversion

Yoke uses the Functional Source License, Version 1.1, ALv2 Future License
(`FSL-1.1-ALv2`). It permits use, modification, and self-hosting for the
license's permitted purposes, including internal use. The license restricts
competing commercial uses as defined in its terms.

Each version becomes additionally available under Apache License 2.0 on the
second anniversary of its release. The conversion applies to that version;
a newer version has its own two-year period.

## Contributing and the CLA

Read [CONTRIBUTING.md](https://github.com/upyoke/yoke/blob/main/CONTRIBUTING.md)
for contribution checks and source-development setup. Contributors sign the
[Contributor License Agreement](https://github.com/upyoke/yoke/blob/main/CLA.md)
on their first pull request by replying to the automated request with the
specified signing comment. The recorded signature covers future contributions.

## Running a source checkout

Cloning the repository lets you read the code. Activating it as the CLI's
source is a separate explicit choice; follow CONTRIBUTING.md.
The wizard's **Edit Yoke source** option accepts an existing checkout or a
public fork. It can power the local CLI and local engine, and an existing
guided self-host can build its server from that checkout. Connecting to an
existing remote server does not redeploy it.
