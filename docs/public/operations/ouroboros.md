# Learning from feedback

<!-- yoke:breadcrumbs -->
[Getting started](../index.md) > [Command and technical reference](../guide/reference/index.md) > [Operations](index.md) > Ouroboros
<!-- /yoke:breadcrumbs -->

Agents file [feedback](feedback.md) about Yoke or their own projects. Curate
reviews every visible note across the universe, groups root causes and turns
approved improvements into work items. Doctor checks declared system health.
The durable note table owns the evidence; events are disposable telemetry.

```text
yoke feedback --to yoke --category failed --evidence 'Yoke recipe failed: ...'
yoke feedback --to universe --category idea --evidence 'Project improvement: ...'
```
