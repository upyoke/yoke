# Curate — Run and Retrospective

```sh
yoke sessions touch --mode curate
```

Follow [cluster-and-work-item.md](cluster-and-work-item.md), then report:

- Entries examined, by category and author.
- Cluster count, promoted Dash/filed item refs, skipped/deferred entries and
  likely-resolved clusters.
- Archived count and remaining unreviewed entries.

Add to `ouroboros/patterns.md` only when the cluster establishes a new recurring
cross-run pattern, rather than as a routine per-run artifact.
