# Terms E–L

<!-- yoke:breadcrumbs -->
[Yoke](../index.md) > [Index](index.md) > E–L
<!-- /yoke:breadcrumbs -->

Draft definitions and links to the current documentation.

## Environment

For deployment, a named destination; in CLI connection selection, a saved connection
profile. These are different uses. [Read more](../deployments/model/flows.md).

## Epic

A workflow for work divided into coordinated tasks. [Read more](../workflows/index.md).

## Event

A recorded occurrence used for observability, attribution and diagnosis. [Read more](../operations/events.md).

## Evidence

Recorded material supporting a result; its subject and scope determine what it proves. [Read more](../verification/platform.md).

## Execution instruction

A project or workflow rule supplied when its declared scope applies to work. [Read more](../projects/execution-instructions.md).

## Execution level

A model-and-effort classification used to place agent work. [Read more](../agents/levels.md).

## Exploratory mission

A QA assignment to investigate an area and report findings rather than follow only
fixed assertions. [Read more](../verification/exploration.md).

## Field note

An observation about a failure, missing guidance or improvement opportunity. [Read more](../operations/ouroboros.md).

## File budget

The declared files an item needs to change when its workflow requires a budget. [Read more](../agents/rules/lanes-and-claims.md).

## Fleet

The collection of sessions and execution resources available to coordinate work. [Read more](../sessions/fleet-policy.md).

## Flow

Usually a deployment flow; a work item's lifecycle is called a workflow. [Read more](../deployments/model/flows.md).

## Frontier

The view of available, blocked, active and completed work used to choose what happens
next. [Read more](../strategy/frontier.md).

## Function

A registered Yoke operation with a defined input and output contract. [Read more](../functions/index.md).

## Function family

A group of related registered operations, such as claims, items or QA. [Read more](../functions/index.md).

## Gate

A condition that must be satisfied before work can advance. [Read more](../workflows/gates.md).

## GitHub integration

The connection used for repository operations, issue mirroring and delivery evidence. [Read more](../github/index.md).

## Harness

The application hosting a coding agent, such as Claude Code, Codex or Cursor. [Read more](../agents/harness-discovery.md).

## Harness session

An agent conversation registered with Yoke, including its identity, liveness and work
ownership. [Read more](../sessions/model/sessions.md).

## Hook

A harness-triggered entry point that supplies guidance or performs checks at session
events. [Read more](../agents/harness-discovery.md).

## Hosted mode

Using a universe hosted by Yoke at upyoke.com. [Read more](../start/modes.md).

## Human acceptance

A person's sign-off required to accept an outcome. [Read more](../verification/platform.md).

## Inbox

Decisions and messages waiting for attention. [Read more](../sessions/inbox.md).

## Installation

Putting the Yoke software and command on a machine. [Read more](../start/install.md).

## Integration

An external service or tool connected to a project's work. [Read more](../projects/capabilities.md).

## Invitation

A way to give another person access to an organization. [Read more](../projects/teammate-invitations.md).

## Issue

A Yoke workflow for a bounded change; a GitHub issue is a separate record that may
mirror it. [Read more](../workflows/index.md).

## Issue mirroring

Copying backlog records into GitHub Issues under the project's sync policy. [Read more](../github/sync.md).

## Item

A recorded unit of work with an intended outcome, workflow and current state. [Read more](../items/index.md).

## Item body

The readable view assembled from an item's structured fields. [Read more](../items/model/body-writes.md).

## Item reference

The project-prefixed identifier people use to name a work item. [Read more](../items/index.md).

## Landing

The recorded arrival of a change in its integration branch. [Read more](../items/model/landings.md).

## Landscape

The strategy document for external research and candidate ideas or imports. [Read more](../strategy/index.md).

## Lane

The isolated checkout assigned to work on an item or task. [Read more](../agents/rules/lanes-and-claims.md).

## Level

See execution level; this is about staffing agent work, not a branch or checkout. [Read more](../agents/levels.md).

## Local mode

Running a private Yoke universe on this machine. [Read more](../start/modes.md).
